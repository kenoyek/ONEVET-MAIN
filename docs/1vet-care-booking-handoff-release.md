# Animal context from care search to booking — 18 November 2026

Pet detail pages now offer Find care alongside the existing consultation action. Active or quarantined farm-group cards offer Find care for this group when they are not already serving an appointment return flow. Both links start veterinary discovery with a specific animal navigation hint.

The directory preserves a valid pet/farm-group UUID hint when applying or clearing filters, and carries it to public provider profiles. Provider back links retain it. The availability panel includes the hint alongside the chosen service, date and time in its protected booking link. Changing the animal context resets that panel and the booking form rather than retaining a previous animal selection.

Hints are restricted to pet:UUID or farm_group:UUID and do not grant access. The booking form still loads only the signed-in owner’s records and accepts only eligible service choices; an unowned or unsupported group cannot become a valid selection. Existing authentication return handling, appointment availability checks, consent, idempotency and provider confirmation rules are unchanged. No booking is automatically submitted, no times are reserved and payments remain unavailable.
