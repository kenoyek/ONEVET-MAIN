# Safer cart quantity editing — 18 November 2026

Cart lines now have a labelled quantity editor supporting direct whole-number entry and Enter or Update quantity. The existing plus/minus controls remain, but minus stops at one; removing an item uses the separate Remove action. Limits are bounded by current stock and the existing 99-unit per-cart ceiling. Invalid, fractional, zero and over-stock entries show inline feedback without changing the saved cart.

Each line explains its quantity limit and unavailable, checking or failed-stock state. Increasing is blocked until stock can be checked successfully, including direct entry. Decreases remain available during a pending or failed check. Unavailable products cannot be edited. When a catalogue refresh reduces the saved quantity or changes availability, the editor resets to that saved value so an obsolete draft cannot conceal the stock adjustment. Controls and feedback use item-specific accessible labels and descriptions.

The component delegates valid updates to the existing cart provider. Account-scoped local storage, server-catalogue refresh, unavailable-item subtotal exclusion, price/stock notices and storage recovery remain unchanged. No orders, payments, stock reservations or backend writes are introduced. Online checkout remains unavailable.

All 542 tests across 127 files pass. Type checking and production build pass; lint has zero errors and nine existing warnings. Validation covers the last-item lower bound, direct and keyboard updates, invalid input, live stock reduction, unavailable products, blocked increases and permitted decreases during uncertain stock. Local Chromium confirms direct edits, unchanged saved quantities after validation errors, blocked increases and permitted decreases after failed stock checks at widths 1440, 390 and 320 without runtime exceptions. Browser scenarios use intercepted synthetic catalogue responses rather than live purchases. No schema migration, backend deployment, cloud environment publication or live Supabase account inspection is included.
