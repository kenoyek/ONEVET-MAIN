# Veterinarian review confirmation — 18 November 2026

Approving or rejecting a submitted veterinarian application now opens a review confirmation instead of immediately changing the profile. The dialog shows the applicant, licence number, private document action and consequences of the selected decision. The administrator must acknowledge reviewing the licence number and document before confirming either decision. This is an explicit acknowledgement, not a claim that the browser can verify that a person read a document.

Cancel makes no decision. While saving, repeat confirmation, cancellation and dismissal are blocked. Failures remain visible in the dialog; successful decisions use the existing dashboard refresh and success feedback. Private document links still use the existing short-lived signed-link service.

Both approval and rejection now condition their updates on the reviewed profile ID, applicant user ID, pending status, licence number and document path. Previously only approval checked the licence snapshot; rejection could affect changed evidence. Incomplete or foreign-document submissions are rejected locally before a write. A zero-row update is treated as changed application or access, never as success. Existing database authorization and atomic audit triggers remain authoritative. No rejection-reason field, message delivery, role grant, organization approval or schema change is introduced.
