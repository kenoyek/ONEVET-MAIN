# Pet onboarding retry edits — 18 November 2026

A new-pet retry after a lost create response now acknowledges the current form details before reporting success. Previously, a duplicate creation ID could be recovered by reading its existing row and immediately continuing, silently leaving any edits made after the first attempt unapplied.

The retry retains the component’s original creation ID. On a duplicate-ID response it first checks that the record exists for the current owner, then applies only the editable pet details to that same ID with an owner-scoped update. A returned row is required. Missing ownership, failed updates and unacknowledged updates keep the form open with its entries and recovery error; they do not produce a success screen or booking return. Owner and creation ID are not part of the update payload. The existing database permissions remain authoritative.

Successful standalone onboarding now carries the saved pet selection into Find care services, matching the existing care-discovery-to-booking handoff. Existing direct booking returns retain the selected service/time context and insert the saved animal hint. Late save feedback is ignored after the component or active account changes, preventing an old pet-name notification from appearing in the next account’s view.

All 582 tests across 130 files pass. Type checking and production build pass; lint reports zero errors and nine existing warnings. Validation covers stable IDs, duplicate-owned recovery, edited retry payloads, owner-scoped updates, missing ownership, missing acknowledgement, account changes, standalone care links and existing booking returns. Local Chromium confirms one stable creation ID, an acknowledged edited retry, an owner-scoped update to one record and saved-pet care context at widths 1440, 390 and 320 without runtime exceptions. Browser scenarios simulate a committed create with a lost response, followed by an edited retry against the same record. No production records, schema migrations, backend deployment, payments or cloud environment publication are included.
