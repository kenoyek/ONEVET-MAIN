# Booking recovery guidance — 18 November 2026

Appointment requests now explain when a previously selected pet or farm group is no longer present in the client’s eligible records for the selected service. Clients can refresh their saved records or browse another service, rather than guessing why their carried selection is missing. A refresh can recover a temporarily unavailable record without clearing entered contact details, address, notes or the chosen time.

The form offers an explicit Refresh saved animals action. A synchronous lock blocks submission from the moment a manual animal refresh starts; refreshing, failed or unknown animal checks cannot produce a ready-to-submit form. Existing owner-scoped queries and service category eligibility remain authoritative for client-side selection, with backend checks unchanged.

Unavailable services, providers that have stopped accepting requests and dates with no available times now offer another care-service path. Alternative links carry only a validated animal navigation hint, not the phone, address, notes, old service or selected time. No booking is created or reserved by recovery actions. Existing consent, slot-conflict handling, idempotent retry and disabled payments remain unchanged.

All 513 tests across 125 files pass. Validation covers missing selections, rechecking eligibility while a ready form exists, preserved contact details/notes after records disappear and recover, unavailable service links and dates without times. Local Chromium confirms missing-animal guidance, blocked submission, alternative links containing only the animal hint, successful record recovery and preserved contact details/notes at 1440, 390 and 320 pixels, without runtime exceptions. Browser checks use synthetic intercepted records and catalogue responses with no production bookings. Type checking and the production build pass; lint has zero errors and nine existing warnings. No database migration, backend deployment, cloud environment publication or changes to prior published work are included.
