# Client setup checklist — 14 November 2026

Customer dashboards now show separate setup steps for pets and farms when the customer cares for both. Legacy livestock owners receive farm setup. Contact completion checks name and phone length using the profile form's existing seven-to-fifteen-digit rule. Progress counts only setup steps; browsing care and shopping remain available immediately and are not treated as incomplete setup tasks.

The checklist reads exact owner-scoped counts independently of dashboard consultations, subscriptions and orders. Loading and failed checks are explicit, failed checks provide retry, and unknown steps never appear complete. A failed lookup warns that saved records may already exist. Account/profile ownership and active status are checked before showing progress. Providers retain organization registration and approval guidance. Registered organizations do not imply approval.

No database migration, registration policy or payment activation is included. Marketplace access means browsing; the existing payment restrictions remain in effect. The changes improve the signed-in getting-started flow, rather than claiming a new live end-to-end signup verification.

Validation includes mixed owners, legacy farm owners, invalid contact phone, failed lookup recovery, account mismatch, provider setup, application/API typechecks, lint and production build. Local Chromium checks use synthetic intercepted backend responses and responsive widths 1440, 390 and 320; no production writes are made.
